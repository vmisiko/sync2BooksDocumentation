The Accounting API writes bookkeeping data — expenses, bills, invoices, and bill payments — into a connected accounting system (QuickBooks Online, Xero, Sage, Dynamics 365 Business Central, or Odoo) on behalf of your customer.

<Note>
This is a **separate product** from the [Compliance API (eTIMS)](/etims-api-reference), which exists to make Kenyan invoices tax-compliant with KRA. See [Which API do I need?](/which-api) if you're not sure which applies to you. They share the same authentication and base URL, but nothing else.
</Note>

## Base URL & authentication

- **Production**: `https://api.sync2books.com`
- **Sandbox**: `https://sandbox-api.sync2books.com` (coming soon)

Every request is authenticated with your API key in the `X-API-Key` header — see [Authentication](/concepts/authentication) for the optional request signature too.

```bash
curl -H "X-API-Key: sk_production_your_api_key_here" \
  https://api.sync2books.com/companies
```

## Resources at a glance

| Resource | What it's for | Key concept |
|----------|---------------|-------------|
| **Companies** | Your customers — the entity everything else is scoped to | [Companies & connections](/concepts/companies-and-connections) |
| **Expenses** | Categorized expenses, receipts, and payments | [Expenses overview](/expenses-overview) |
| **Bills** | Accounts-payable documents (money you owe suppliers) | — |
| **Invoices** | Accounts-receivable documents (money customers owe you) | — |
| **Bill Payments** | Payments applied against one or more bills | — |
| **Attachments** | Receipts/documents attached to an already-synced transaction | — |
| **Sync** | Track and retry the async batch every write creates | [The sync model](/concepts/sync-model) |

Almost every write is **asynchronous**: you get a `syncBatchId` back immediately, and confirm the outcome via the Sync endpoints — see [The sync model](/concepts/sync-model).

## Response format

```json Success
{ "data": { ... } }
```

```json Error
{ "statusCode": 400, "message": "Validation failed", "error": "Bad Request" }
```

## Rate limits

- **Standard**: 100 requests/minute per API key
- **Burst**: up to 200 requests/minute for short bursts

Headers: `X-RateLimit-Limit`, `X-RateLimit-Remaining`, `X-RateLimit-Reset`. See [Errors & rate limits](/concepts/errors-and-rate-limits) for the full model.
