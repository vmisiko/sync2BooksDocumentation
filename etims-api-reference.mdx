The Compliance API connects your invoicing to **KRA eTIMS** — register a catalog, manage stock, and turn a sale into a KRA-signed receipt, without building the OSCU device protocol yourself.

<Note>
This is a **separate product** from the [Accounting API](/api-reference), which syncs bookkeeping data to accounting systems. See [Which API do I need?](/which-api) if you're not sure which applies to you. They share the same authentication and base URL, but nothing else.
</Note>

## Base URL & authentication

All endpoints are scoped to a company: `/companies/{companyId}/integrations/etims/…`

- **Production**: `https://api.sync2books.com`
- **Sandbox**: `https://sandbox-api.sync2books.com` (coming soon)

```
X-API-Key: sk_production_…    (or sk_development_…)
```

### Optional HMAC signature

For stronger security you may sign requests — when signature headers are present, both are validated:

| Header | Value |
|--------|-------|
| `X-Signature` | `HMAC-SHA256(clientSecret, "{METHOD}{PATH}{BODY}{TIMESTAMP}")`, hex |
| `X-Timestamp` | Unix time in **milliseconds**; must be within 5 minutes of server time |

The signature is optional — the API key alone authenticates if you omit both headers. See [Authentication](/concepts/authentication).

### Errors

| Status | Meaning |
|--------|---------|
| `401` | Missing/invalid API key, or invalid signature |
| `409` | Conflict (e.g. connecting a company that's already connected) |
| `429` | Rate limit exceeded (per-application, per-minute) |

## Conventions — read this before you integrate

These four points explain almost every "why doesn't this work" question:

- **Async endpoints** return `{ "syncBatchId": "<uuid>" }`. Confirm the result via [Tracking Results](/etims-tracking-results).
- **`branchId`** in Catalog/Sales/Stock is your branch **key** (e.g. `HQ`), set when the branch was created — **not** the branch UUID used by the [Branches](#branches) endpoints. Mixing these up is the single most common integration mistake.
- Sales/stock line items reference the **item `id`** returned by Sync2Books, not your `externalId`.
- For valid field **codes** (tax category, units, packaging, payment, classification), see [Codes & Values](/etims-codes).
