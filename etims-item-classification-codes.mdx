Every item needs a **classification code** (`itemClsCd`) before it can be registered with
KRA — see [Item Attributes](/etims-item-attributes). This page lists the classification codes KRA
publishes, so you can pick the one that best matches a product without digging through the raw
TIS specification.

<Note>
  This table is a snapshot. KRA maintains the list on its own servers and can add or retire codes, so the live
  lookup is authoritative: search it with `GET /v1/lookups/classifications?query=...`, or fetch one code with
  `GET /v1/lookups/classifications/{code}`. Both need the `lookups:read` scope. See
  [Items](/etims-guide-items#find-the-codes) and the [TIS specification](https://kra.go.ke/images/publications/TIS-for-OSCU--VSCU-Technical-Specifications-v2.0.pdf).
</Note>

## Columns

| Column | Meaning |
|--------|---------|
| `itemClsCd` | Item Classification Code — the value you send as `classificationCode` |
| `itemClsNm` | Item Classification Name |
| `itemClsLvl` | Item Classification Level — where the code sits in KRA's classification hierarchy (1 = broadest) |

## Related FAQ

**Which item classification code should I use?** Pick the most specific code (highest `itemClsLvl`)
that describes the product. If nothing matches closely, use the broadest code for the right
category rather than an unrelated specific one — KRA validates that the code exists, not that it's
the ideal match.
