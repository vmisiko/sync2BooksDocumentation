Sync2Books is **two separate products**. They solve different problems, have different data models, and each has its own dashboard, its own API keys, its own base URL and its own docs. Most of the confusion in these docs in the past came from mixing the two together, so start here.

## Side by side

|  | **Accounting API** | **Compliance API (eTIMS)** |
|---|---|---|
| **Answers the question** | "How do I get this expense/bill/invoice into my customer's books?" | "How do I make this sale legal under Kenyan tax law?" |
| **The external system** | An accounting package your customer already uses (QuickBooks, Xero, Sage, Dynamics, Odoo) | The Kenya Revenue Authority's eTIMS network (via an OSCU device) |
| **How you connect a company** | OAuth, via the [Link component](/link-integration) or an `authUrl` | KRA PIN and device details entered in the **compliance dashboard**, then an API key from its **Integrations** page |
| **Authentication** | `X-API-Key` header, with a `sk_...` key. See [Authentication](/concepts/authentication). | `x-api-key` header or a bearer token, with a `cmp_sk_...` key. See [Authentication & API keys](/etims-authentication). |
| **Core objects** | Expense, Bill, Invoice, Bill Payment | Item, Sale, Credit note, Branch |
| **Geography** | Anywhere | Kenya only |
| **Reference docs** | [Accounting API](/api-reference) | [eTIMS API](/etims-api-reference) |

The two use different base URLs, so keep each product's calls pointed at its own. The Accounting API's is in [Environments & base URLs](/concepts/environments), and the eTIMS API's is in the [eTIMS API reference](/etims-api-reference).

## Using both together

A Kenyan business often needs both: you write an invoice through the Accounting API, and the sale is issued through the eTIMS API for a KRA-signed receipt. The two flows are independent — an eTIMS sale doesn't require an accounting connection, and an accounting invoice doesn't require eTIMS. Where both are in use, the receipt can be attached to the matching invoice in the connected accounting system.

## Still not sure?

- Building expense reports, bill pay, or invoicing for a business **outside Kenya**, or that doesn't need KRA compliance yet? → **Accounting API**.
- Your customer is Kenyan and legally required to issue eTIMS-compliant receipts? → **eTIMS API**. You may still want the Accounting API alongside it if they also want their books synced.
